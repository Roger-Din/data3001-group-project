# RQ1 generated results

These files are generated by `notebooks/01_rq1_forecasting/01_velocity_persistence_baseline.ipynb`.

- `velocity_persistence_error_curve.png`: held-out median separation error by lead time with the interquartile range.
- `velocity_persistence_example_trajectory.png`: representative test trajectory whose 72-hour error is near the test median.
- `velocity_persistence_lead_metrics.csv`: test-set metrics for every lead time from 1 to 72 hours.
- `velocity_persistence_test_case_metrics.csv`: integrated and final errors for each of the 757 test cases.
- `velocity_persistence_summary.csv`: compact headline values for reporting and the poster.

Do not edit generated result files manually; rerun the notebook instead.
