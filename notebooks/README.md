# Notebook guide

Use the folders in numerical order:

| Folder | Purpose | Status |
|---|---|---|
| `00_preliminary/` | Original exploration, QC, segmentation, proposal analysis and the Chinese progress overview | Completed preliminary work |
| `01_rq1_forecasting/` | Bilingual RQ1 baselines, learned/statistical models and held-out evaluation | Completed modelling workflow |
| `02_rq2_regime_analysis/` | Performance comparison across physical ocean regimes | Planned |
| `03_rq3_conformal_prediction/` | Conformal calibration, coverage and prediction-region evaluation | Planned |

The RQ1 folder provides matched `en/` and `zh/` notebooks; run either language in numerical order. Create new notebooks inside the folder for the research question they answer. Do not overwrite preliminary notebooks merely to add later modelling results.
