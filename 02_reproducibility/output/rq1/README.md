# RQ1 generated results / RQ1 生成结果

All files in this folder are reproducibly generated by the notebooks in [`../../notebooks/01_rq1_forecasting/`](../../notebooks/01_rq1_forecasting/).

- [`en/`](en/): English tables and figures for teaching staff and formal reporting.
- [`zh/`](zh/): 中文表格和图片，用于组内交流。

Both directories contain identical numerical results. Text, table headings and figure labels are localised independently.

## File groups

- `velocity_persistence_*`: velocity-persistence test metrics, summary and representative trajectory.
- `spatial_mean_flow_*`: training-only flow field, fallback diagnostics, test metrics and representative trajectory.
- `ridge_*`: grouped Ridge model selection, fitted parameters and held-out results.
- `fnn_*`: grouped FNN configuration selection, training histories, fitted parameters and held-out results.
- `var1_*`: pooled VAR(1) coefficients, grouped diagnostics and held-out results.
- `knn_*`: grouped KNN selection, neighbour diagnostics and held-out results.
- `rq1_three_model_*` through `rq1_six_model_*`: successive common-case model comparison tables and figures.

The most complete comparison is `rq1_six_model_comparison.png` and its corresponding CSV file.

## Reproducibility

Do not edit these generated files manually. Rerun the notebooks in numerical order within the desired language directory. The large local Parquet modelling tables remain excluded from Git, but all compact metrics, fitted parameter arrays and poster-ready figures are tracked here.
