# Champion spatial-generalization outputs

Generated by `notebooks/04_generalization/02_champion_models_spatial_generalization_CN.ipynb` using frozen Region-A champion configurations and ten external ocean regions.

| File | Meaning |
|---|---|
| `champion_spatial_case_metrics.csv` | One row per external case and model with lead-time errors and trajectory metrics. |
| `champion_spatial_region_metrics.csv` | RMSE, median error and ITE for every model-region pair. |
| `champion_spatial_summary.csv` | Mean/median performance across the ten regions and skill versus persistence. |
| `champion_spatial_bootstrap_vs_persistence.csv` | External-drifter bootstrap interval for each model's mean region-level RMSE difference from persistence. |
| `champion_spatial_generalization_summary.png` | Main comparison figure. |

Negative RMSE differences in the bootstrap table favour the model over persistence. Random Forest is the only learned champion that is reliably better than persistence in this fixed ten-region experiment.
